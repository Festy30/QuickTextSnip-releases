# QuickTextSnip

Програма для Windows, що поєднує:

- **Flash Paste** — вікно швидкого вибору фрагмента за гарячою клавішею (пошук, ↑/↓, Enter);
- **aText** — скорочення, які розкриваються самі під час набору в будь-якій програмі;
- **QuickTextPaste** — гарячі клавіші, що відкривають спливаюче меню фрагментів або вставляють фрагмент, групи, змінні.

Живе в треї (біля годинника). Дані лежать у `%APPDATA%\QuickTextSnip\snippets.json`.

## Як зібрати й запустити

1. Встановіть **.NET 8 SDK**: https://dotnet.microsoft.com/download
2. У папці проєкту:

```
dotnet run
```

Щоб отримати окремий `.exe` (один файл, без встановлення .NET на інших комп'ютерах):

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Готовий файл буде в `bin\Release\net8.0-windows\win-x64\publish\QuickTextSnip.exe`.

## Як користуватися

| Дія | Як |
|---|---|
| Швидка вставка (вікно пошуку) | `Ctrl+Alt+Space` → пошук → `Enter` |
| Спливаюче меню фрагментів | `Ctrl+Alt+M` (або будь-яка своя комбінація, див. нижче) |
| Скорочення | наберіть, наприклад, `;sig` в будь-якій програмі — воно замінюється на текст |
| Менеджер фрагментів | подвійний клік по іконці в треї |
| Налаштування | меню іконки в треї → **Налаштування…** |
| Гарячі клавіші фрагментів | кнопка **⌨ Гарячі клавіші…** внизу менеджера або меню іконки в треї |

### Вікно швидкої вставки

Відкривається гарячою клавішею з «Налаштувань» (за замовчуванням `Ctrl+Alt+Space`). Поки поле пошуку порожнє, показується **дерево папок**: папки з підпапками розгортаються кліком, Enter або стрілкою →, згортаються ←; поруч із папкою — кількість фрагментів, розгорнуті папки запам'ятовуються. Щойно починаєте друкувати, дерево замінюється плоским списком найкращих збігів (по назві, скороченню, папці й тексту; точні збіги скорочення й початок назви — вгорі), де біля назви сірим показано папку. У кожному рядку праворуч — скорочення. Вікно вузьке й високе (близько 80% висоти екрана), стоїть по центру, унизу — прев’ю тексту. Керування: ↑/↓, PageUp/PageDown, Enter або клік по фрагменту — вставити, Esc — закрити.

### Розмір вікон і зовнішній вигляд

Розмір вікна швидкої вставки змінюється мишею: потягніть за край чи кут вікна. Новий розмір зберігається й діє при наступному відкритті. Так само запам'ятовується розмір вікна менеджера. Усі вікна програми (менеджер, швидка вставка, гарячі клавіші, налаштування) мають єдиний вигляд: дерево папок із шевронами й кольоровими крапками, закруглене виділення, плашки скорочень, плоскі кнопки з акцентною кнопкою дії.

### Гарячі клавіші фрагментів (як у QuickTextPaste)

У вікні **Гарячі клавіші фрагментів** оберіть модифікатор (наприклад, «Ліва клавіша Windows»), клавішу, що саме вона робить, і натисніть **Додати**:

- **Спливаюче меню — усі групи** — меню біля курсора, групи як підменю;
- **Спливаюче меню — окрема група** — плоский список фрагментів однієї групи;
- **Вставити конкретний фрагмент** — одразу вставляє обраний фрагмент.
- **Кілька фрагментів на одну комбінацію** — просто додайте ту саму комбінацію ще раз з іншим фрагментом (дія «Вставити фрагмент»). Коли на комбінації більше одного фрагмента, вона відкриває меню з усіх них.

**Кнопка миші як модифікатор.** У списку «Комбінація» оберіть «Ліва кнопка миші (утримувати)» (або праву, або обидві, або Ctrl + кнопка), а в списку клавіш — наприклад `1`. Тоді: тримаєте ліву кнопку й натискаєте 1 — відкривається меню фрагментів або вставляється фрагмент. Для правої кнопки програма гасить контекстне меню при відпусканні.

Щоб змінити вже додану комбінацію, виберіть її в списку й натисніть **Змінити вибрану** (або двічі клацніть по рядку): значення перейдуть у поля внизу, а кнопка «Додати» стане «Зберегти зміни».

Комбінації з клавішею Windows (наприклад, `Win+A`) перехоплюються програмою й не доходять до системи. У меню біля кожного фрагмента показано його скорочення, а внизу є пункт **QuickTextSnip** для відкриття менеджера.

### Кнопка «⚙ Опції»

У лівій колонці менеджера: **Імпорт…** і **Експорт…**; **Зберегти резервну копію…** та **Відновити з резервної копії…** (ZIP замінює все, включно з файлами, налаштуваннями й клавішами; старий JSON — лише фрагменти й папки); **Розгорнути / Згорнути всі папки**; **Сортувати фрагменти в усіх папках за назвою**; **Скинути лічильники використання**; **Гаряча клавіша швидкої вставки…** (швидка зміна комбінації, що відкриває вікно швидкої вставки); **Налаштування…**; **Відкрити папку з даними**; **Відкрити журнал**.

### Папки, підпапки та порядок

Зліва в менеджері фрагменти показано деревом папок. Праве клацання по списку відкриває меню:
- **Нова папка / підпапка…** — створює папку (якщо виділено папку чи фрагмент у ній — підпапку в ній); кнопка «📁 Нова папка» над списком робить те саме;
- **Перейменувати папку…**, **Видалити папку…** (фрагменти з видаленої папки не пропадають, а переміщуються на рівень вище);
- **Кнопки над списком:** верхній ряд — «＋ Новий» і «📁 Нова папка»; нижній — ▲ ▼ ✎ 🗑 — ▲/▼ зсувають виділену папку або фрагмент на одну позицію (так само, як пункти «Вгору/Вниз» у меню); ✎ перейменовує папку або переводить до поля «Назва» фрагмента;
- **Призначити гарячу клавішу…** (ПКМ по фрагменту чи папці) — відкриває вікно «Натисніть комбінацію»; після запису й «Додати» прив'язка одразу з'являється в «Гарячі клавіші…» (фрагмент — вставка, папка — меню папки). Один фрагмент (папка) — одна клавіша: нова комбінація замінює попередню (так само у вікні «Гарячі клавіші»). Якщо комбінація вже зайнята іншими фрагментами, фрагмент додається до неї в меню; інакше програма питає про заміну;
- **Значок клавіатури** у дереві праворуч від назви показує фрагменти й папки, до яких прив'язано гарячу клавішу; при наведенні курсора підказка «Гаряча клавіша: …» з комбінаціями. Оновлюється після змін у «Гарячі клавіші…» та після «Призначити гарячу клавішу…»;
- **Після збереження фрагмента** (нового чи зміненого; кнопка або Ctrl+S) форма очищується для наступного, а збережений лишається виділеним у дереві — випадково його не відредагуєш; клік по ньому знову відкриває його для змін.;
- Після призначення чи видалення гарячої клавіші форма редактора теж очищується (з питанням про незбережені зміни), щоб нову заготовку не вписати в стару;
- **Налаштування → «Винятки та дозволи»** — окремий розділ (після «Скорочення»): режим «Скрізь, крім винятків» / «Лише у вибраних програмах і вікнах», білий список програм і заголовків вікон, програми-винятки. Галочка «Застосовувати ці правила також до гарячих клавіш фрагментів» (вимкнено за замовчуванням) поширює правила на гарячі клавіші клавіатури/миші; у «чужому» вікні такі комбінації передаються програмі як звичайні. «Швидка вставка» (вікно вибору) відкривається завжди й усюди; «Вставити останній» у «чужому» вікні нічого не робить (комбінацію зареєстровано в системі);
- У вікні швидкого вибору (Ctrl+D) текст фрагмента в нижньому перегляді показується і при наведенні миші на фрагмент (а не лише при виділенні стрілками); коли курсор поза списком — показується виділений;
- **Скриншоти в фрагментах** (формат «Великий текст (візуальний редактор)»): Ctrl+V зі скриншота (Win+Shift+S), перетягування файлу в текст або кнопка 📷; картинка стискається (до 1100 px) і зберігається всередині фрагмента, а при вставці йде разом із текстом (HTML). Лише для програм, що приймають HTML із картинками (Outlook, Word, Gmail, більшість веб-редакторів); у простих чатах картинка може не вставитись, лишиться текст. У вікні Ctrl+D біля такого фрагмента є позначка 🖼;
- **Прикріплені файли** (docx, xlsx, pdf — будь-які): у редакторі поле «Прикріплені файли» з кнопками «📎 Додати файл…» і «✕». Файли копіюються в `%APPDATA%\QuickTextSnip\files\<Id фрагмента>`. Під час вставки програма спершу вставляє текст, а потім віддає файли способом із Налаштувань → Загальне → «Прикріплені файли»: за замовчуванням — маленьке вікно біля курсора, з якого файл перетягується мишею в чат (~25 с, не забирає фокус; підходить для сайтів, що не приймають вставку файлів), або другий Ctrl+V (пошта, Outlook, Gmail), або обидва способи. У вікні Ctrl+D біля фрагмента показано 📎 і імена файлів. Файли входять в експорт ZIP та в повні/автоматичні копії (ZIP); в експорт CSV/JSON — ні;
- **Налаштування → Загальне → «Меню швидких відповідей (гаряча клавіша) повинно з'являтися»**: біля вказівника миші (меню відкривається вище й правіше курсора, щоб не закривати текст; якщо зверху немає місця — нижче), біля каретки або у центрі екрана. Підписи груп (колишній GroupBox) тепер мають колір теми — у темній темі вони читаються;
- **Швидкі змінні** під кнопкою «Макроси»: плашки «Дата і час {datetime}», «Дата {date}», «Час {time}», «Буфер 1–3 {clipboard:N}» — клік вставляє змінну в текст у місці курсора; один рядок (у вузькому вікні переноситься на другий), підказка — у кнопці «?». Права частина редактора має вертикальну прокрутку: поле тексту не стискається менше ~220 px, а нижні блоки (клавіша, файли, змінні) докручуються; власна тонка смуга прокрутки в стилі програми (`ScrollHost.cs`: закруглений повзунок, акцент при наведенні/перетягуванні, клік по доріжці — сторінка; колесо над полем тексту прокручує текст, над рештою — праву частину); у списках смуги системні, але темні (`Theme.EnableDarkScrollbars`);
- **Видалення комбінації:** кнопка «✕» поруч із «⌨ Призначити…» (і пункт «Видалити гарячу клавішу» в меню ПКМ) знімає призначену клавішу з фрагмента чи папки;
- **Поле «Гаряча клавіша»** під текстом (перед «Макроси») в редакторі — лише для перегляду (редагувати не можна): показує всі комбінації, призначені відкритому фрагменту; кнопка «⌨ Призначити…» поруч відкриває запис нової комбінації;
- **Дублювати фрагмент** (Ctrl+D у списку) — створює копію виділеного фрагмента одразу під ним у тій самій папці з назвою «… (копія)»; скорочення в копії порожнє (воно має бути унікальним), лічильник використання нульовий; курсор одразу в полі «Назва» для перейменування;
- **Вгору / Вниз** — змінює порядок фрагмента всередині папки або папки серед сусідніх; **Сортувати за назвою (А→Я)** впорядковує фрагменти папки за алфавітом.

Перетягуйте мишею: фрагмент на папку — переміщує в її кінець, фрагмент на інший фрагмент — ставить перед ним, папку на папку — робить підпапкою, папку на порожнє місце — повертає на верхній рівень.

У полі «Папка» редактора шлях можна писати й вручну: `Старт чатів/Привітання`. Імпорт (JSON, CSV) теж розуміє такі шляхи. Спливаюче меню показує папки як вкладені підменю, а фрагменти — у вашому порядку; у гарячих клавішах меню окремої папки показує й її підпапки.

### Формати фрагментів

У менеджері для кожного фрагмента обирається формат: **звичайний текст**, **форматований текст (RTF)** з панеллю оформлення або **HTML (код)**. Форматування зберігається при вставці у Word, Outlook, пошту; у простих редакторах вставляється звичайний текст.

### Візуальний редактор («Великий текст»)

У менеджері в полі «Формат» оберіть **«Великий текст (візуальний редактор)»**. З'явиться редактор з панеллю, як у веб-редакторах: шрифт і розмір, жирний/курсив/підкреслений/закреслений, верхній і нижній індекс, колір тексту й виділення, нумеровані та марковані списки, відступи, цитата, вирівнювання, посилання, зображення за адресою, таблиці, горизонтальна лінія, відміна/повтор, вставка змінних, кнопка **Source** (HTML-код). Ctrl+S зберігає фрагмент.

Редактор працює на Microsoft Edge WebView2 (на Windows 11 він уже є; на Windows 10 його можна встановити з сайту Microsoft). Якщо WebView2 немає, замість редактора показується звичайне поле для HTML-коду.

### Змінні в тексті фрагмента

| Змінна | Що підставляється |
|---|---|
| `{date}` `{time}` `{datetime}` | поточна дата / час / обидва |
| `{date:dd MMMM yyyy}` | дата у вашому форматі (так само для `{time:…}` і `{datetime:…}`) |
| `{clipboard}` | поточний вміст буфера обміну |
| `{cursor}` | де залишити курсор після вставки |
| `{input:Назва}` | перед вставкою програма спитає значення; `{input:Назва=за замовчуванням}` — із початковим значенням |

### Імпорт та експорт

У менеджері — кнопки **Імпорт…** та **Експорт…**:

- імпорт: JSON (QuickTextSnip), CSV/TSV (стовпці на кшталт `Abbreviation`, `Text`, `Name`, `Group`), plist із macOS Text Substitutions (його експортує aText для Mac);
- експорт: JSON (з повним форматуванням і **гарячими клавішами** фрагментів та папок), **ZIP** (те саме + **прикріплені файли**) або CSV (лише текст, без клавіш). Імпорт ZIP додає фрагменти, клавіші й файли (файли прив'язуються до нових копій фрагментів). Під час імпорту JSON клавіші прив'язуються до доданих чи вже наявних фрагментів; якщо фрагмент уже має свою клавішу — вона не змінюється. Старі файли експорту (без клавіш) клавіш не містять — їх треба експортувати знову.

Дублікати пропускаються, а скорочення, що вже зайняті, прибираються й про це повідомляється.

## Налаштування

Меню іконки в треї → **Налаштування…**: гаряча клавіша швидкої вставки (клацніть у поле й натисніть комбінацію), розкриття скорочень, робота скорочень в українській розкладці (за тими самими фізичними клавішами), автозапуск разом з Windows.

## Якщо гаряча клавіша не спрацьовує

Поки вікно «Гарячі клавіші» чи «Налаштування» відкрите, комбінації вимкнені — закрийте його й перевірте. У меню іконки є пункти «Діагностика гарячих клавіш (журнал)» і «Відкрити журнал». Програма веде журнал `%APPDATA%\QuickTextSnip\log.txt`: у ньому видно, чи було помічено натискання, яку привʼязку виконано і яка була помилка.

## Обмеження

- Скорочення й гарячі клавіші фрагментів не спрацьовують у програмах, запущених **від імені адміністратора**, якщо QuickTextSnip запущено без прав адміністратора.
- Вставка йде через буфер обміну; після неї повертається попередній **текст**. Якщо в буфері була картинка чи файл, вони не відновляться.
- Радимо починати скорочення з префікса (`;`, `/`), інакше можливі випадкові спрацювання в звичайному тексті.
- Деякі комбінації з Win зарезервовані Windows. Для швидкої вставки (налаштовується окремо) вони можуть не спрацювати, а в «Гарячих клавішах фрагментів» перехоплюються програмою.

## Опції (налаштування)
«⚙ Опції → Налаштування…» або пункт у треї відкриває діалог із розділами зліва:
- **Загальне** — повний текст у підказках/прев'ю, запам'ятовування останнього фрагмента, автозакриття вікна вибору, автозапуск, місце появи вікна вибору (центр / біля каретки / попередня позиція; вікно можна переносити за верхню смугу), мова.
- **Гарячі клавіші** — клавіша вікна вибору.
- **Скорочення** — розкриття скорочень, фізичні клавіші і **де вони працюють** — режим «Скрізь, крім програм-винятків» (`ExcludedApps`) або «Лише у вибраних програмах і вікнах» (білий список `AllowedApps`, див. розділ нижче); винятки: у вказаних програмах (назва процесу без .exe, напр. `KeePass`, `WindowsTerminal`; можна вибрати із запущених) скорочення не розкриваються, а гарячі клавіші та швидкий вибір працюють. Зміна діє одразу після OK.
Інші розділи додаватимуться.

### Теми
«Опції → Тема»: Класична, Neon Cyber, Frost Glass, Carbon Amber. Вибір зберігається (`ThemeId`), застосовується до менеджера, вікна вибору та опцій (темні теми фарбують і заголовок вікна). Меню в треї та вбудований HTML-редактор лишаються світлими.

### Власні вікна (SkinForm)
Усі вікна без системного заголовка: власна смуга з назвою та кнопками ─ ▢ ✕, перетягування, зміна розміру за краї, закруглені кути (Windows 11), закруглені кнопки й поля у кольорах теми.

Подвійне натискання клавіші вікна вибору (напр. Ctrl+D двічі) відкриває головне вікно керування.

### Іконка
Assets\app.ico (блискавка у фігурних дужках; джерело — Assets\icon.svg, PNG-розміри поруч). Вбудована в exe, трей і вікна.

### Імпорт з QuickTextPaste
«⚙ Опції → Імпорт…» приймає `.ini` QuickTextPaste: тексти потрапляють у папки за комбінаціями (наприклад, «Ліва кнопка миші + 2»), назви беруться з міток, створюються гарячі клавіші; %pptxt% → {clipboard}, %DD%/%MM%/%YYYY% → {date:…}.

## Імпорт з FlashPaste
Резервну копію FlashPaste (`Shura.db`) конвертовано у `FlashPaste_import.json` (403 фрагменти, структура папок збережена, RTF-фрагменти лишаються RTF). Імпорт: ⚙ Опції → Імпорт… → вибрати файл.

## Порядок папок
Папки перетягуються мишею: на верхню/нижню третину рядка іншої папки (з'являється лінія вставки) — стають перед/після неї на тому ж рівні; на середину — всередину. Порядок зберігається в `Folders` і використовується в усіх деревах.

## RTF у темній темі
Чорний (типовий) колір тексту RTF-фрагментів у редакторі підміняється кольором теми; при збереженні повертається чорний.

## Порядок папок усюди
Швидке вікно, спливаюче меню і вікно гарячих клавіш використовують той самий порядок папок, що й головне вікно.

## Макроси
Кнопка «{ } Макроси ▾» під полем тексту вставляє змінну в місце курсора (для звичайного, RTF і HTML-тексту).
Підтримуються: `{date}` `{time}` `{datetime}` (+ формат `{date:dd MMMM yyyy}`), `{clipboard}`, `{cursor}`,
`{input:Назва=значення}`, `{list:Назва=а|б|в}` (вибір зі списку у вікні запиту), `{random:а|б|в}` (випадковий рядок),
`{number:1-100}` (випадкове число), `{env:USERNAME}` (змінна оточення), `{file:шлях}` (текст із файлу), `{remark:текст}` (коментар, не вставляється).
Не реалізовано (були у FlashPaste): словник, клавіші керування, друк рядка, відкриття програм/файлів.

## Історія буфера обміну
Програма стежить за буфером обміну (`ClipboardHistory.cs`, AddClipboardFormatListener) і пам'ятає 10 останніх скопійованих текстів — лише в пам'яті, на диск не пишеться. Макроси `{clipboard:1}` (останнє скопійоване), `{clipboard:2}` (попереднє) … `{clipboard:5}`; `{clipboard}` — поточний вміст. Власні вставки програми в історію не потрапляють. Вмикається в Опції → Загальне.

При повторному імпорті файлу фрагмент, який уже є, але лежить в іншій папці, переноситься в папку з файлу (лічильник «Переміщено»).

ПКМ по папці → «Видалити папку разом з фрагментами…» (з підтвердженням; прибирає також пов'язані гарячі клавіші). ПКМ по фрагменту → «Видалити фрагмент…».

2. Запустіть `build-installer.bat`: він робить `dotnet publish` (один самодостатній exe) і збирає `installer\QuickTextSnip.iss`.
3. Готовий файл: `installer\Output\QuickTextSnip-Setup-1.0.0.exe` — його й даємо людям.

## Налаштування → «Дані та копії»
Імпорт, експорт, збереження/відновлення резервної копії та службові кнопки (папка з даними, журнал) перенесені з меню «⚙ Опції» в налаштування (розділ «Дані та копії»; код — `DataTools.cs`). Пункт швидкої гарячої клавіші з меню прибрано (вона є в налаштуваннях).
Автокопії (`AutoBackup`): вмикаються галкою; період у днях; скільки останніх копій зберігати; папка (за замовчуванням `%APPDATA%\QuickTextSnip\Backups`). Копія робиться при запуску, якщо настав час, і далі перевіряється кожні 30 хв; файли `QuickTextSnip-auto-дата_час.json`, зайві найстаріші видаляються. Кнопка «Створити копію зараз». Перед відновленням з копії автоматично зберігається `QuickTextSnip-before-restore-…json` (не видаляється).

## Вставка останнього рядка
Налаштування → «Гарячі клавіші»: окрема комбінація (наприклад Ctrl+O), що одразу вставляє останній вставлений фрагмент (`LastSnippetId`). Лише клавіатурні комбінації; не повинна збігатися з клавішею вікна вибору та гарячими клавішами фрагментів. Кнопка «Вимкнути» очищає її.

## Мови інтерфейсу (українська / російська)
Налаштування → Загальне → «Мова». Зміна діє після перезапуску (програма пропонує перезапуститись сама, нова копія запускається з `--restart`).
Як це працює: усі тексти в коді — українські, але обгорнуті `Loc.T("…")` / `Loc.F("шаблон {0}", …)`; для російської мови переклад береться зі словника `LocRu.cs` (ключ — український текст). Сторінка візуального редактора перекладається через `Loc.Html` (фрагменти в `LocRu.Html`). Мова зберігається в `AppSettings.Language` ("uk"/"ru"), читається на самому старті (`Loc.InitFromFile`).
Нові тексти: пишіть українською в `Loc.T("…")` і додавайте пару в `LocRu.Map`; без перекладу показується український текст. Не локалізуються: журнал, назви папок і фрагментів (це дані користувача), приклади при першому запуску.
Інсталятор: додано російську мову (`installer\QuickTextSnip.iss`).

## Кошик
Видалені заготовки (кнопка «Видалити», пункт «Перемістити у кошик» у меню правої кнопки, видалення папки разом із заготовками) не зникають, а потрапляють у кошик (`Trash.cs`, `TrashForm.cs`; зберігається в `snippets.json` у списку `Trash`, тому входить і в резервні копії).
- **Ctrl+Z** у списку (дереві) менеджера повертає все, що було видалено останньою дією (папка з усім вмістом повертається разом). Те саме — «Опції → Скасувати останнє видалення».
- **Кнопка 🗑 над списком** (праворуч від ✎) або **Опції → Кошик…** — вікно зі списком (назва, папка, дата видалення): «Відновити» (також подвійний клік/Enter), «Видалити назавжди» (Delete), «Очистити кошик». Відновлена заготовка повертається у свою папку (папку створює заново, якщо її не було) — у кінець списку.
- Автоочищення: налаштування → «Дані та копії» → «Кошик»: скільки днів зберігати (за замовчуванням 30, 0 — не очищати). Перевіряється при запуску та кожні 30 хв.
- Обмеження: гарячі клавіші, що вказували на видалену заготовку (при видаленні папки), не відновлюються; порожні папки після видалення не повертаються.

## Частота використання
Налаштування → Загальне → «Частота використання»:
- **Ставити частіше вживані заготовки вище** (за замовчуванням вимкнено) — у вікні швидкого вибору та спливаючому меню заготовки в папці сортуються за кількістю вставок (потім за ручним порядком). У менеджері порядок завжди ручний.
- **Показувати біля назви, скільки разів вставляли** (за замовчуванням увімкнено) — суфікс `·12×` у менеджері, швидкому виборі та меню. Для заготовок без вставок не показується.
Лічильник збільшується при кожній вставці; «Опції → Скинути лічильники використання» обнуляє його.

## Ширина списку в менеджері
Між списком заготовок і редактором — роздільник із «ручкою»: у спокої на ньому тонкі точки, при наведенні з'являється плашка зі стрілками ◀ ▶ і курсор ↔. Потягніть, щоб розширити чи звузити список (під час перетягування показується акцентна лінія, а ширина змінюється при відпусканні кнопки — без мерехтіння); подвійний клік перемикає вузький (300) і широкий (520) вигляд (мін. 220 px; редактор зберігає мін. 460 px). Ширина запам'ятовується (`ManagerTreeWidth`) і відновлюється при наступному відкритті.

## Де працюють скорочення (білий список)
Налаштування → Скорочення → «Де працюють скорочення»:
- **Скрізь, крім програм-винятків** (за замовчуванням) — список винятків за назвою процесу.
- **Лише у вибраних програмах і вікнах** — скорочення розкриваються тільки там, де збігається правило: програма (назва процесу, напр. `chrome`) + необов'язковий текст у заголовку вікна (без урахування регістру). Так можна дозволити скорочення лише на певних сайтах у браузері: заголовок вкладки містить назву сторінки/сайту, тому правило `chrome` + текст із заголовка діє лише на цих вкладках.
- Кнопка **«Визначити активне вікно»**: за 3 секунди перемкніться на потрібну сторінку — програма підставить назву процесу й заголовок (суфікс «- Google Chrome» прибирається). Заголовок за потреби скоротіть до частини, що однакова на всіх сторінках сайту.
- Обмеження: браузер віддає у заголовку назву сторінки, а не адресу; якщо назви сторінок на сайті змінюються і не мають спільної частини, правило не спрацює.
- Це стосується лише розкриття скорочень під час набору; гарячі клавіші та вікно швидкого вибору працюють у всіх програмах. Код: `KeyboardHook.SetAllowedApps`.

## Запис комбінації (вікно «Гарячі клавіші»)
Замість двох випадаючих списків («Комбінація» і «Клавіша») — одне поле запису (`ComboCapture.cs`): клацніть у нього й просто виконайте комбінацію:
- **Клавіатура:** Win + A, Ctrl + Alt + K, Alt + F2 тощо (модифікатор обов'язковий; Shift окремо не підходить).
- **Утримувана кнопка миші + клавіша:** затисніть ліву (або праву) кнопку й натисніть клавішу, наприклад «ліва кнопка + 1» → `MouseL+1`.
- **Клік мишею:** середня кнопка, бічні (назад/вперед), Ctrl/Alt/Win + ліва чи права кнопка, ліва + права разом. Простий клік лівою/правою кнопкою не записується (ним ставиться фокус у поле).
- Після запису поле саме виходить із режиму запису й показує комбінацію (щоб записати іншу — клацніть у поле знову).
- Комбінація показується плашками `[Win] + [A]`. Поки поле в фокусі, його клавіатуру перехоплює тимчасовий хук (комбінації з Win не відкривають меню Windows, Alt/Tab не діють); **Esc** без модифікаторів виходить із запису, фокус також знімається кліком поза полем.
- Кнопка «Змінити вибрану» підставляє комбінацію вибраної привʼязки в це поле.
Формат запису в файлі не змінився (`LWin+A`, `MouseL+1`, `Ctrl+MouseMiddle`…), тож наявні привʼязки працюють як раніше.

## Вікно «Гарячі клавіші»: дерево вибору
У дереві «Група / Фрагмент» (праворуч) папки за замовчуванням **згорнуті**; над деревом — **пошук** за скороченням, назвою, групою та текстом фрагмента (кілька слів — усі мають знайтися). Під час пошуку показуються лише збіги, папки розгортаються, перший знайдений фрагмент виділяється. Пошук діє і в режимі «окрема група» (показує групи, де є збіги). При зміні існуючої привʼязки потрібний фрагмент відкривається автоматично.

## Порядок фрагментів у меню комбінації (перетягування)
У вікні «Гарячі клавіші» рядки списку можна **перетягувати**: порядок привʼязок однієї комбінації = порядок фрагментів у меню, яке відкривається за нею (перший зверху). Під час перетягування показується лінія вставки (над/під рядком — залежно від того, у якій половині рядка курсор); біля країв список прокручується. Перенести можна лише в межах однієї комбінації. Порядок зберігається в `SnippetHotkeys`.


### Зміна розміру вікна менеджера
Поки вікно тягнуть за край, розкладка редактора оновлюється ~15 разів на секунду (а не на кожен піксель), після відпускання — повний перерахунок. Це зменшує «фрізи». Код — `ManagerForm.cs` (`ResizeBegin/ResizeEnd`).


### Підказка «?» біля поля «Скорочення»
У менеджері поруч із підписом «СКОРОЧЕННЯ» є знак «?»: клік відкриває невелике вікно з поясненням, що таке скорочення, як ним користуватися й порадами (префікс `;`, унікальність, без пробілів). Код — `Fields.Labeled(..., help)` і `Fields.ShowHelp` (`Fields.cs`); так само можна додати «?» до будь-якого іншого поля.


### Плавність прокрутки
`ScrollHost` пересуває панель вмісту одним системним викликом (`SetWindowPos`), без повторної розкладки; під час перетягування повзунка оновлення зливаються (≤ ~60/с), панель вмісту має подвійну буферизацію.


### Автоперевірка збірки (GitHub Actions)
Файл `.github/workflows/build.yml`: після кожного push на GitHub Windows-сервер збирає проєкт (`dotnet build`) і публікує готову збірку як файл «QuickTextSnip-win» (вкладка Actions → запуск → Artifacts, зберігається 14 днів). Зелена галочка — компілюється; червоний хрестик — у лозі кроку «Build» видно помилки. Налаштування: створити репозиторій на GitHub (можна приватний) і завантажити туди вміст папки проєкту.


### Резервні копії у форматі ZIP (пакет 1)
- **Формат:** `data.json` (фрагменти, папки, кошик, налаштування, гарячі клавіші) + папка `files/<Id фрагмента>/…` з прикріпленими файлами. Код — `BackupPackage.cs`.
- **Зберегти копію…** — ZIP (повна) або JSON (лише дані, як раніше). **Автокопії** тепер теж ZIP і містять файли та клавіші; старі `.json`-копії лишаються й чистяться за тим самим лімітом.
- **Відновити з копії…** — ZIP відновлює **все**: фрагменти, папки, кошик, прикріплені файли, налаштування й гарячі клавіші (крім папки автокопій). Перед заміною програма автоматично зберігає копію поточного стану (`before-restore`). Після відновлення вікно налаштувань закривається, а програма пропонує перезапуск. Старий JSON відновлює лише фрагменти й папки.
- **Імпорт ZIP** приймає і пакет експорту, і повну копію: фрагменти додаються до наявних (дублікати пропускаються), клавіші й файли прив'язуються до доданих.


### Автотести і звіт про помилку (пакет 2)
- **Автотести** (`tests/QuickTextSnip.Tests`, xUnit): змінні (`{input}`, `{list}`, `{cursor}`, `{date}`, екранування в HTML), гарячі клавіші (розбір, порівняння), шляхи папок, імпорт (нові Id, перенос клавіш, дублікати, конфлікт скорочень), ZIP-пакети (копія й експорт із файлами та клавішами). Тести працюють у тимчасовій папці даних (`SnippetStore.DirOverride`), справжні дані не чіпають. На GitHub вони запускаються автоматично на кожен push (крок «Test» у `.github/workflows/build.yml`); червоний хрестик — або помилка компіляції, або тест, що не пройшов (у лозі видно який).
- **Звіт про помилку** (`CrashReporter.cs`): якщо програма натрапила на необроблену помилку, у `%APPDATA%\QuickTextSnip\Crashes` зберігається `crash-<дата>.txt` (версія, система, стек помилки, кінець журналу), а програма пропонує відкрити папку зі звітом. Помилка в інтерфейсі не закриває програму. Тексти фрагментів у звіт не потрапляють. Зберігаються останні 30 звітів. Кнопка «Звіти про помилки» — в Налаштування → Дані та копії → Службове.


### Розумний пошук (пакет 3)
Єдиний пошук для вікна Ctrl+D і для поля «Пошук…» в менеджері (код — `SnippetSearch.cs`, клас `SearchQuery`):
- слова запиту шукаються в назві, скороченні, папці й **тексті** фрагмента; усі слова мають збігтися; порядок результатів: скорочення → початок назви → назва → … → текст;
- **неправильна розкладка:** якщо слово нічого не знайшло, пробується його ж в іншій розкладці — `ghbdsn` знайде «Привіт», `руддщ` знайде «Hello» (українська й російська ЙЦУКЕН);
- **нечіткий пошук:** одна помилка (слова 5–8 літер) або дві (від 9 літер), перестановка сусідніх літер, пропущені літери назви (`пдкл` → «Підключення»); короткі слова (до 4 літер) без помилок;
- **підсвічування збігів** у назві й у плашці скорочення (кольором акценту) у списку Ctrl+D та в дереві менеджера, включно з варіантами «в іншій розкладці» і нечіткими.

## Інтерфейс (пакет 4)
- Підказки «?» тепер і біля полів **Гаряча клавіша**, **Папка**, **Формат**, біля змінних (замість системної підказки — вікно в стилі програми) та біля **«Що робити»** у вікні гарячих клавіш.
- Списки (дерево фрагментів у менеджері й у швидкому меню) мають тонку смугу прокрутки в стилі програми (`ThinScrollBar.cs`, ту саму використовує редактор). Горизонтальної смуги немає — довгі назви обрізаються «…».
- Під час вибору фрагмента редактор прокручується нагору (видно назву й скорочення); мінімальна висота редактора зменшена (720 → 660).

- Виправлено вузьке вікно підказки «?» (розмір тепер рахується явно).
- У вікні гарячих клавіш довгий опис запису комбінації перенесено в підказку «?» (раніше текст обрізався).
- Поле запису комбінації: зрізано крайній ряд пікселів (зайва світла риска зверху й ліворуч існувала з самого початку).

## Синхронізація між комп'ютерами (пакет 5)
- Налаштування → Дані та копії → **Синхронізація між комп'ютерами**: кнопка «Папка даних…» переносить `snippets.json` і `files\` у вибрану папку (наприклад, у OneDrive/Dropbox/Google Drive; створюється підпапка `QuickTextSnip`). «Стандартна» повертає `%APPDATA%\QuickTextSnip`.
- Вказівник на папку лежить локально (`%APPDATA%\QuickTextSnip\location.txt`), тому на кожному ПК його задають окремо. Журнал, звіти про помилки, WebView2 і автокопії за замовчуванням лишаються локальними (`SnippetStore.LocalDir`).
- Якщо в обраній папці вже є дані (з іншого ПК) — запитує: використати їх, замінити поточними (старий файл зберігається поруч) чи скасувати. Перед будь-яким переносом створюється ZIP-копія `QuickTextSnip-before-move-….zip` у локальній папці Backups.
- Після зміни програма перезапускається. Якщо папка недоступна (диск/хмара не підключені), програма працює зі стандартною й показує попередження — щоб не створити порожні дані.
- Захист від втрати: якщо файл змінили ззовні (інший ПК), а програма збирається його перезаписати, попередня версія зберігається як `snippets.conflict-….json`. Програма стежить за файлом (FileSystemWatcher) і пропонує перезапуск, коли дані оновились з іншого ПК. Одночасна робота на двох ПК не підтримується.
- Тести: `SyncTests.cs`.

## Автооновлення (пакет 6)
- Нові версії публікуються як реліз у **публічному** репозиторії `Festy30/QuickTextSnip-releases` (лише `QuickTextSnip-win.zip`, без коду). Програма раз на добу (через хвилину після запуску) питає GitHub API про останній реліз, порівнює тег (`v1.2.3`) із власною версією (`<Version>` у csproj; під час релізу підставляється з тегу).
- Якщо версія новіша: вікно «Так — оновити / Ні — пізніше / Скасувати — не нагадувати про цю версію». «Так» завантажує архів із прогресом, розпаковує у тимчасову папку, перевіряє наявність `QuickTextSnip.exe`, закриває програму, а допоміжний `update.cmd` копіює файли поверх і запускає програму знову. Дані (`%APPDATA%`) не чіпаються.
- Якщо програма лежить у папці без права запису (Program Files) — відкривається сторінка релізу для ручного оновлення.
- Налаштування → Дані та копії → «Оновлення програми»: поточна версія, перемикач перевірки, «Перевірити зараз»; те саме — у меню трею «Перевірити оновлення…».
- Випуск: тег `vX.Y.Z` у приватному репозиторії → workflow `.github/workflows/release.yml` збирає, тестує, пакує й створює реліз у публічному (секрет `RELEASES_TOKEN`). Текст змін береться з `RELEASE_NOTES.md` (необов'язково).
- Налаштування одноразові: публічний репозиторій релізів + токен (fine-grained PAT з правом Contents: Read and write лише на цей репозиторій) у Secrets приватного репозиторію.
- Тести: `UpdaterTests.cs`.
- build.yml: прибрано прапорець -warnaserror- (новий SDK 10 на runner його не розпізнає).
